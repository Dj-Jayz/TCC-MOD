# TCC-MOD
Note: You need an Android device or emulator to install these files. Unfortunately there is nothing I can do about this.
Install fv file explorer, navigate to Android/data/com.ea.gp.pvzheroes/files/...

cache/bundles/files/cards (card_data_1)
cache/bundles/files/loc (en_11)
il2cpp/Metadata (global-metadata)

android is weird about letting you navigate to these folders, i recommend navigating to folders first and favoriting them before you copy paste the modded files from your downloads 

If FV File Explorer isn’t working, here’s a second (better?) way of installing mods, which I use for Bluestacks (unfortunately does not seem to work on my phone):

Install ZArchiver
In the Explore tab, navigate to Android/data/com.ea.gp.pvzheroes/files/cache/bundles/files/cards
Open card_data in ZArchiver
Go up 2 levels to /files/cache/bundles/files, favorite the cards and loc folders (hold down on them to open up the options menu)
Go up 3 more levels to /files, go into il2cpp and favorite Metadata
Go back to Media Manager and import the new files to be installed
Open the files you just imported in Media Manager, go up 2 levels and favorite whatever folder your files were uploaded in
Now that the folders with the old and new files are in your favorites, copy the new files into PvZH
Open PvZH, it might crash a couple of times first. If done correctly you should see the new card data (meaning your mod installed correctly)
